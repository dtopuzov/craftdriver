# Code of Conduct

CraftDriver should be a useful, respectful place to build browser automation tooling.

## Expected Behavior

- Be kind and constructive.
- Assume good intent while still being clear about technical problems.
- Keep issues and pull requests focused on the project.
- Welcome beginners and help them find the right docs or reproduction shape.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Dismissive or hostile comments about someone's background, identity, or skill level.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.

## Reporting

If you see behavior that makes the project less safe or productive, open an issue with minimal public detail and ask for a private maintainer contact path.

Maintainers may edit or delete comments, lock threads, or block users when needed to keep the project healthy.
